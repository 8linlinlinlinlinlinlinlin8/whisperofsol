# Whisper of sol — Android dApp Source Code

Hackathon submission: Android client source for the Whisper of sol
solana-mobile dApp. This zip contains ONLY the source code needed to
build the APK.

## What's NOT in this zip (and why)

| excluded | reason |
|----------|--------|
| `src/android/pda/` | Solana program source (Anchor / Rust). Smart-contract code, not APK. |
| `src/android/wallet/` | Deploy keypair. Never commit secrets. |
| `dockerfile`, `docker-compose.yml`, `scripts/`, `wiki/` | Platform bootstrap files for our local dev environment, not part of the dApp. |
| `dapp/build/`, `dapp/app/build/` | Gradle build artifacts, regenerated by `./gradlew assembleDebug`. |
| `dapp/.gradle/`, `dapp/.kotlin/` | Build tool caches. |
| `dapp/output/`, `dapp/dist/` | APK + zips — APK is in the sibling zip. |
| `dapp/*.png` (root), `dapp/screenshots/` | Visual probe dumps from on-device debugging. |
| `dapp/app/src/test/` | Paparazzi headless screenshot test — improves confidence but not needed to build APK. |

## Build

```bash
cd dapp
./gradlew :app:assembleDebug
# APK output: app/build/outputs/apk/debug/app-debug.apk
```

Requirements: Android Studio (or just JDK 17 + Android SDK 36), Kotlin Compose.

## Stack

- Kotlin + Jetpack Compose, Material 3
- Mobile Wallet Adapter (MWA) — Solana wallet connect / sign
- In-app 4-locale switcher (system / en / zh-CN / zh-TW / ja) using
  `resources.updateConfiguration` + Compose state — no `activity.recreate()`
- Paparazzi for headless screenshot tests (not bundled; see above)
